# VouchFor

Social vouching and trust network graph.

## Features
- Multi-chain support (Base & Stacks)
- Secure Contract Logic
- React/Next.js Frontend

## Contracts
- Base: `contracts/base/src/VouchFor.sol`
- Stacks: `contracts/stacks/contracts/vouchfor.clar`

## Setup
```bash
pnpm install
pnpm dev
```
